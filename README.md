# NyumbaFinder Kenya

A simple rental-house search prototype for Kenya.

## Website

When GitHub Pages deployment completes, visit:
https://talam100.github.io/nyumbafinder-kenya/

## Deployment

The site is a static HTML page in `index.html`. GitHub Actions deploys the repository to GitHub Pages on every push to `main`.

In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.

## Prototype limitations

- The included houses are demo listings, not verified rental offers.
- Listings submitted through the form and saved favourites are stored only in the current browser.
- There is no shared database or user account system yet.
- Verify a property and its landlord before paying any deposit.
